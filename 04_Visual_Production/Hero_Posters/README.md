# Visual Assets

This folder is reserved for images, icons and other visual resources used in the infographic scripts.  As a text‑based knowledge base, the current version does not include images.  To enrich your Obsidian vault, you can download high‑quality photographs or illustrations of each species and place them here.  Name files clearly (e.g. `siberian_tiger.jpg`, `pallas_cat.png`) and reference them in your markdown files using Obsidian’s image syntax (`![[filename.jpg]]`).

For sources of free and reputable wildlife images consider:

- **Wikimedia Commons:** Many species images are available under Creative Commons licences.
- **IUCN Red List Species Accounts:** Often include range maps.
- **Public domain wildlife photography databases.**

Ensure that you respect copyright licences when adding images.
