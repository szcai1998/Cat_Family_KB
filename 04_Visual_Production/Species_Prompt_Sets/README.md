# Species Prompt Sets

Each species in the atlas can have its own set of image generation prompts.  These prompts should reference the species’ key features, habitat and mood.  For example, a snow leopard prompt may describe a rocky, snowy mountain landscape with a sleek spotted cat, while a serval prompt may involve tall golden grass and a cat listening intently.

Organise files by species name, e.g. `Jaguar_Prompts.md`, and include multiple prompts for hero images, range maps and trait illustrations.
