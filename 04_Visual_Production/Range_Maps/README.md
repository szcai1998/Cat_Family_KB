# Range Maps

Range maps illustrate the geographic distribution of each species.  Use vector formats (e.g. SVG) or high‑resolution rasters to allow zooming without loss of clarity.  Colour coding can indicate core and peripheral populations or highlight habitat fragmentation.

When creating maps, reference authoritative sources such as the IUCN Red List and scientific publications.  Provide a legend and scale.  For now, this folder contains placeholders awaiting map assets.
