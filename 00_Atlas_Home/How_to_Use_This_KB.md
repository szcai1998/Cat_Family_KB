# How to Use This Knowledge Base

This atlas is organised like a museum library. Each folder corresponds to a section of the museum and each markdown file is an exhibit or module. Here’s how to navigate and contribute:

1. **Home and Index** – Start at the [[Cat_Family_Atlas_Home.md|home page]] to understand the purpose of the project. The **[[Species_Index.md|Species Index]]** lists every species with links to their profiles.
2. **Taxonomy and evolution** – The **`01_Taxonomy_and_Evolution`** folder contains background notes on the family Felidae, the distinction between _Pantherinae_ and _Felinae_, family tree diagrams and notes about taxonomic caveats. Read these files to understand the evolutionary context for the species.
3. **Species profiles** – The **`02_Species_Profiles`** folder holds a markdown file for each species. Each profile follows a common template: core identity, museum summary, range, habitat, diet, behaviour, build and scale, signature traits, conservation, production notes and internal links. Citations appear at the end of important facts using tether notation (e.g. 【960819529586131†L75-L104】) to trace information back to reliable sources.
4. **Exhibit modules** – In **`03_Exhibit_Modules`** you will find folders for range and habitat, diet and hunting, behaviour and ecology, build and scale, signature traits, conservation and 3D model notes. These files are placeholders for deeper modules where you can later expand on particular aspects of a species’ biology or ecology.
5. **Visual production** – The **`04_Visual_Production`** folder contains subfolders for prompt templates, species‑specific prompts and visual assets such as hero posters, preview cards, range maps, hunting posters, anatomy posters and 3D model placeholders. The markdown files reference these placeholders using relative paths so you can drop in your own images later.
6. **Ecology comparisons** – The **`05_Ecology_Comparisons`** folder contains pages comparing cats by ecological themes such as apex predators, arboreal cats, mountain specialists, desert and dryland cats, grassland hunters, speed versus stealth and sociality. These comparisons help reveal patterns across species.
7. **Conservation notes** – The **`06_Conservation`** folder provides context on conservation status, threats, human–wildlife conflict, habitat fragmentation and poaching. It also lists conservation organisations and sources for further reading.
8. **Templates** – In **`99_Templates`** you’ll find the raw templates used to create species profiles, exhibit modules, visual prompts and comparison pages. Use these as a starting point when adding new species or modules.

When contributing, follow these principles:

- **Accuracy** – Check facts against primary sources. Include citations for all non‑trivial statements, especially sizes, weights, ranges and conservation status. Use sources from recognised institutions like National Geographic, Smithsonian, IUCN or peer‑reviewed publications.
- **Modularity** – Keep information in small, reusable modules. For example, separate range and habitat details into their own files within the `03_Exhibit_Modules` folder.
- **Consistency** – Follow the templates for species profiles and modules so readers know what to expect. Use the same section headings and order for each species.
- **Clarity** – Write in clear, plain language. Avoid jargon unless it is defined. Keep lists concise and use paragraphs for richer descriptions.
- **Documentation of sources** – Always cite sources using the tether notation. Each citation is a pointer to a line range in a web‑scraped source or PDF (e.g. 【362655593780840†L60-L114】). Citations should appear immediately after the fact they support.

By following these guidelines, you’ll help build a trustworthy and accessible knowledge base of the cat family.
