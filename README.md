# Cat Family Atlas

> _A living, modular knowledge base exploring every wild and domestic species of the Felidae — the cat family._

---

## Welcome to the Museum

The **Cat Family Atlas** is organised like a natural-history museum. Each folder is a gallery, each markdown file is a placard or exhibit module. Whether you are a curious beginner or a seasoned naturalist, this atlas is written for you — in plain, vivid language that brings the world's cats to life.

## Contributing

- Always follow the templates in `99_Templates` when creating new profiles or modules.
- Write in a clear, vivid, layman-friendly tone — imagine you are writing a museum placard.
- Use relative paths for all internal links.
- Commit with Conventional Commits format: `feat(species): add fishing cat profile`.
