# Exhibit Module Template

Use this template to create detailed modules (range & habitat, diet & hunting, behaviour & ecology, build & scale, signature traits, conservation) for a specific species. Place the file in the appropriate folder within `03_Exhibit_Modules` and name it using the species name and topic, e.g. `Tiger_Range_and_Habitat.md`.

```
# {Species} – {Module topic}

## Overview

Summarise why this topic is important for understanding the species.  Explain how the species’ range, diet, behaviour, etc. relate to its ecology and conservation.

## Key Information

- **Geographic distribution / Prey items / Social structure / Morphometrics** (adapt depending on topic).
- Provide data tables, maps, diagrams or lists.
- Cite sources for each factual statement.

## Interpretation and Comparisons

Explain what the data reveal about the species.  Compare with other species where relevant (e.g. range size relative to puma or lynx).

## Visuals and Assets

Describe or embed maps, charts, infographics or photos.  Use placeholders if assets are pending.

## References

Include full citations or footnotes for sources used in this module.

```
