# Exhibit Modules

The **Exhibit Modules** directory contains specialised pages that provide deeper information on particular aspects of each species.  While each species profile offers a concise overview, modules in this section can expand on specific themes such as range and habitat, diet and hunting strategy, behaviour and ecology, anatomical scale, signature traits and conservation status.  Modules are grouped by topic and can be reused across multiple species.

Each module folder includes placeholder Markdown files that you can replace or extend as you build out the atlas.  For example, to create a range and habitat module for the jaguar, create a file in `Range_and_Habitat` called `Jaguar_Range_and_Habitat.md` and include maps, descriptions and citations.

## Module folders

- **Range_and_Habitat/** – detailed descriptions of geographic ranges, distribution maps and habitat preferences.
- **Diet_and_Hunting/** – information about prey species, hunting methods and feeding ecology.
- **Behavior_and_Ecology/** – coverage of social systems, activity patterns, communication and ecological roles.
- **Build_and_Scale/** – comparative measurements, body proportions, locomotion and biomechanics.
- **Signature_Traits/** – anatomical or behavioural features that make each species unique.
- **Conservation/** – expanded conservation status details, threats and ongoing recovery efforts.
- **3D_Model_Notes/** – notes and scripts for generating or refining 3D models of cats.

At this stage these folders contain only **README** files as placeholders.  When you add new modules, remember to cite reliable sources.
