# Conservation Modules

Use this folder for species‑specific conservation briefs.  Each brief should include:

- Current IUCN status and population trend.
- Key threats such as habitat loss, poaching, prey depletion and conflict with humans.
- Ongoing conservation projects, protected areas, and legislation.
- Recommendations for research, management and public engagement.

These modules can expand upon the summary information in the species profiles.  Cite the IUCN Red List and other credible conservation sources.
