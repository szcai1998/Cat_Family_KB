# Range and Habitat Modules

This folder stores range maps and habitat descriptions for individual species. Each file should include a brief introduction, a map or placeholder for a map, and a detailed description of where the species occurs, including continents, countries, ecoregions and typical habitats (forests, grasslands, mountains, wetlands, etc.). Use authoritative sources such as the IUCN Red List and peer‑reviewed papers to support your statements.
