# Build and Scale Modules

The purpose of this folder is to host comparative analyses of body size, weight, proportions and locomotor abilities. Use tables, diagrams and 3D model annotations to illustrate how species differ in length, height at the shoulder, tail length, skull shape and other morphological parameters. Also discuss biomechanical adaptations such as the cheetah’s semi‑retractable claws or the puma’s powerful hind legs.

These modules can help readers visualise scale differences among cats and appreciate how form influences function.
