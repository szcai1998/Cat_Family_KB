# Family Tree Poster

This script outlines a poster that visualises the **Felidae family tree**.  Use it as a guide for designing an infographic in Obsidian or other graphic tools.

## Concept

Create a hierarchical diagram showing how living cat species are grouped.  The top node represents **Felidae**, branching into **[[Pantherinae]]** (big cats) and **[[Felinae]]** (small cats).  Each branch then splits into genera and species.  The aim is to convey both the taxonomic relationships and the diversity of forms.

## Structure

1. **Title:** “Felidae: The Cat Family”
2. **Top level:** Felidae node with a short description (two sub‑families, 14 genera, 45 species【844804255495323†L318-L324】).
3. **Second level:** Two branches labelled **Pantherinae** and **Felinae**.
4. **Third level:** Under Pantherinae, show genera *Panthera* and *Neofelis*; under Felinae, show key genera (*Felis*, *Acinonyx*, *Puma*, *Lynx*, *Caracal*, *Leptailurus*, *Leopardus*, *Otocolobus*).  Use arrows or lines to connect.
5. **Fourth level:** Add boxes for each species covered in this knowledge base.  For example:
   - *Panthera*: [[Siberian Tiger]], [[African Lion]], [[Jaguar]], [[African Leopard]], [[Snow Leopard]]
   - *Neofelis*: [[Clouded Leopard]]
   - *Felis*: [[Domestic Cat]]
   - *Acinonyx*: [[Cheetah]]
   - *Puma*: [[Cougar - Puma]]
   - *Lynx*: [[Eurasian Lynx]]
   - *Caracal*: [[Caracal]]
   - *Leptailurus*: [[Serval]]
   - *Leopardus*: [[Ocelot]]
   - *Otocolobus*: [[Pallas’s Cat]]
6. **Annotations:** For each species node, add a brief tag or icon indicating a key trait (e.g. fastest, largest, best jumper) and colour‑code according to sub‑family.
7. **Legend:** Provide a legend explaining colour codes and symbols (e.g. stars for endangered status).
